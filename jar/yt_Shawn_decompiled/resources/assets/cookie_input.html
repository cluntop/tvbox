🍪 YouTube Cookie 获取

选择以下方式之一获取 YouTube Cookie

Via 浏览器获取 Cookie 最简单
🌟 Via 浏览器操作步骤：
1. 手动打开 Via 浏览器 App
2. 在地址栏输入：m.youtube.com
3. 登录你的 YouTube 账号
4. 登录后，点击左上角盾牌+勾图标
5. 点击【View Cookie】
6. 点击【复制】按钮
7. 切换到下方【手动粘贴方式】并提交
💡 Via 浏览器优势：
• 一键查看和复制 Cookie，无需开发者工具
• 轻量无广告，速度快
• Google Play: 搜索 "Via Browser"
📱 如果没有 Via 浏览器：
可以使用其他浏览器（Chrome/Firefox），需要用开发者工具获取 Cookie（操作较复杂）
手动粘贴 Cookie
Via 浏览器获取 Cookie（推荐）：
1. 在 Via 打开 m.youtube.com 并登录
2. 登录后，点击左上角盾牌+勾图标 🛡️✓
3. 点击【View Cookie】
4. 点击【复制】按钮
5. 粘贴到下方输入框并提交

Chrome/其他浏览器获取 Cookie：
1. 在浏览器打开 m.youtube.com 并登录
2. 按 F12 打开开发者工具（或长按网址栏选"审查元素"）
3. 切换到【控制台/Console】标签
4. 输入：document.cookie 并回车
5. 复制输出的内容（Cookie 字符串）
6. 粘贴到下方输入框并提交
💡 Via 浏览器下载：
Via 是一个轻量、无广告的浏览器，支持直接查看和复制 Cookie
Google Play: 搜索 "Via Browser"
💡 提示：
• 方法 1 可能只能获取部分 Cookie（非 HttpOnly）
• 如果方法 1 失败，请使用方法 2 手动粘贴
• 电视端会自动填入接收到的 Cookie
